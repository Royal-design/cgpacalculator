# 🎓 Mini CGPA Calculator

**Mini CGPA Calculator** is a lightweight web app built with React and TypeScript that helps students easily calculate their CGPA based on course units and grades. The app features a clean, responsive interface using Chakra UI and handles dynamic input for multiple courses.

## [click the link to access the site](https://royal-design.github.io/cgpacalculator/)

## 🚀 Features

- ➕ Add and remove course entries dynamically
- 📊 Real-time CGPA calculation as you input data
- 🎓 Supports different grade point systems
- 📱 Fully responsive with Chakra UI

---

## 🧰 Tech Stack

- **React** – Frontend framework
- **TypeScript** – Strongly typed codebase
- **Chakra UI** – Component-based styling and layout
